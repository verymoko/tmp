# Sibaristica · карточка кофе

Реализация выбранного узла [Figma 19108:2756](https://www.figma.com/design/gFlYUy3WbjTYnR5ViiC1kL/?node-id=19108-2756). Ширина оригинала 420 px; медиаблок 463,672 px. На широком экране карточка центрируется, на узком текст и теги переносятся без обрезания.

**Деплой:** https://sibaristica-card-19108.verymoko.workers.dev

## Запуск

Нужны Node.js 22+ и Python 3 для локального HTTP-сервера. Зависимостей сборки нет.

```sh
cd sites/sibaristica-card
npm run build
npm run dev
```

Локальный адрес: http://localhost:4173. `dist/public/` содержит статический сайт; `dist/worker.mjs` — самодостаточный Cloudflare Worker с теми же файлами. Встроенные ресурсы позволяют развернуть небольшой прототип одним multipart-запросом без отдельных хранилищ и временных Figma URL.

## Токены

Источник — корневой [`../../tokens.json`](../../tokens.json) в GitHub. Сборка читает его непосредственно и генерирует `public/tokens.generated.css`: `--spacing-0`, `--spacing-1`, `--spacing-2` и другие используемые интервалы. Исходный JSON сохранён без изменений, Git blob: `24cd401724bf9a4f9e05ea594b59d8ecd8806b91`.

Цвета и семейство шрифта отсутствуют в JSON, а многие другие группы содержат нулевые значения. Они не подменяют корректные значения макета: недостающие параметры вынесены в `public/tokens.figma.css` с указанием Figma-источника. Стили компонента ссылаются на переменные обоих файлов. Происхождение текущей сборки доступно в `/tokens.provenance.json`.

После изменения корневого `tokens.json` выполните `npm run build` и деплой. Веб-странице не нужны GitHub API, токены доступа или сетевое получение стилей.

## Поведение и ресурсы

- Избранное переключается настоящей кнопкой, хранится в localStorage и синхронизируется между вкладками. При запрете хранилища работает до закрытия страницы.
- Нажатие на упаковку открывает просмотр. Закрытие: кнопка, Esc или нажатие на подложку; фокус возвращается к кнопке.
- Изображение и иконка экспортированы из соответствующих слоёв Figma и сохранены локально. Скриншот карточки не используется в реализации.
- Onest Variable 5.3.1: локальные кириллический и латинский WOFF2 из `@fontsource-variable/onest`; лицензия SIL OFL находится в `public/fonts/OFL.txt`.
- Сохранены оригинальные текст, изображение и цена. На упаковке в самом макете написано другое название кофе; это исходное содержимое дизайна.

## Проверка

Проверено в Chromium на ширинах 320, 390, 420, 768, 1024 и 1440 px: загрузка всех ресурсов и Onest, отсутствие горизонтального переполнения, переключение и сохранение избранного, открытие с клавиатуры, Esc и возврат фокуса. На ширине 420 px геометрия сверена со скриншотом Figma. Проверены HTTP GET/HEAD, ETag/304, 404 и 405 собранного Worker.

## Повторный деплой

`cloudflare-deploy.json` содержит имя Worker, дату совместимости и включённые logs/traces. На машине с авторизацией Cloudflare:

```sh
npm run check
npm run build
node scripts/deploy.mjs
```

`CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` передаются через окружение, в репозитории секретов нет. Для записи нужен доступ Workers Scripts Write к выбранному аккаунту. Скрипт обновляет Worker с именем из конфигурации и включает его адрес workers.dev.
